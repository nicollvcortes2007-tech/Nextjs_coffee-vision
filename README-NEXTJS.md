# Coffee+Vision — proyecto con Next.js y Node.js

Se conservó el código React que enviaste: los archivos originales de `src/pages`, `src/components`, `src/plantillas`, `src/routes`, `src/App.jsx`, `src/main.jsx`, estilos e imágenes no fueron reescritos.

Se añadió una capa de entrada de Next.js para ejecutar la aplicación React existente, junto con carpetas base de la guía Coffee+Vision. Las rutas y la navegación actuales siguen siendo administradas por React Router, tal como estaban en tu código.

## Requisitos
- Node.js 18.17 o superior
- npm

## Ejecutar
```bash
npm install
npm run dev
```
Abre http://localhost:3000

## Importante
`package.vite-original.json` conserva el manifiesto original del proyecto Vite como respaldo. El `package.json` principal se preparó para Next.js. No se modificaron las pantallas ni los componentes originales.
